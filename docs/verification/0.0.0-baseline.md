## Measured workload shape (soak evidence)

Reduced from `tools/bench/results/soak-0.0.0/state/athanor.db` (20 jobs,
~35 minutes):

| Measure | Value |
|---|---:|
| Events | 2,570 |
| Event JSON | 583 KB (~29 KB/job; avg 227 B/event; max 1.1 KB) |
| Artifacts | 221 files / 932 KB (~47 KB/job) |
| Live DB | 1.9 MB |
| State dir incl. 10 backups | 6.6 MB |
| Events per job | ~128 |

Implication: at 10–100 jobs/day, the event log is a ~0.3–3 MB/day writer and
would take years to reach 10 GB. Artifacts, exports, and per-job scratch are the
growth risks to watch. This is why the retention decision is "retain forever,
measure, and GC scratch", not "prune the audit log."
