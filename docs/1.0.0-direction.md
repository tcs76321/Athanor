## What 1.0.0 means

1.0.0 is not "more features." It is the point where Athanor is:

- **trustworthy** — containment, recovery, observability, and a completed
  security audit hold under real use;
- **measured** — a mature, MCE-sensitive frozen benchmark and a concluded
  statistical study, not just directional anecdotes;
- **self-improving** — selection (technique, model, routing, escalation) is
  learned from grounded outcomes and the human anchor, reversibly;
- **pleasant** — a **first-class GUI** covers the daily loop, not a CLI-only
  workflow;
- **portable** — a signed install, a Core Pod, and a clean upgrade on Linux and
  macOS.

0.0.x is where the study runs; 1.0.0 is where its questions are answered and the
system is a daily driver.

## The five musts

| # | Pillar | Acceptance theme |
|---|---|---|
| 1 | **First-class GUI** (main focus) | The operator runs a full day without the CLI: onboarding/qualification, project interview + plan, presentation, review queue, morning digest/approval ledger, project/portfolio, task/DAG, evidence/benchmark dashboard, settings, notifications, accessibility |
| 2 | **Validated self-improvement** | The 0.0.x study concludes; selection is learned from grounded outcomes with the human anchor; novelty reset; project-scoped vs global changes; weight-level learning only if the corpus justifies it (frozen judge, HITL promotion, rollback) |
| 3 | **Mature benchmark** | Large, MCE-sensitive, per-major frozen; regression dashboard and version diffs; mechanism metrics; statistical power; v2 cut at 1.0.0 |
| 4 | **Trustworthy** | §31.3 audit complete; containment gates; scanner maturity (YARA/ClamAV); recovery/SLOs; long-run stability; migrations/backup/restore; observability |
| 5 | **Distribution** | Signed installers, auto-update, multi-arch Core Pod (arm64/amd64), Linux/macOS; fresh install <15 min; one-command rollback |

## Committed additions

These are in 1.0.0 (picked deliberately; they increase trust/observability, not
surface area):

6. **Portfolio / multi-project.** Project budgets and prioritization; machine-time
   and review-time allocation; a morning meeting across projects. With
   single-slot execution, this is queue/attention policy, not parallelism.
7. **Deterministic `media` verifier.** Closes the last advisory archetype:
   structural conformance (container/format, dimensions/duration, required
   metadata, explicit constraints), with semantic quality staying
   judge-advisory. **Definition required** — "deterministic" must mean
   measurable properties, not generated content quality; it may need media
   tooling in the Job Pod.
8. **Full Statistics / Memory-Browser views.** The MCE made observable:
   outcomes, cost, insights, chunks, retrieval, compaction, benchmark/evidence.
   This is the observability layer **inside** pillar 1, not a separate pillar.

## Unnecessary by design

- **External skills, plugins, and MCP.** Every need they serve has an internal,
  measured equivalent — personas/prompt/context, CorrectionRecords, the MCE,
  the built-in tool set, DAG/scheduler, and selection/escalation
  ([ADR-0079](adr/0079-no-skills-runtime.md)). An external layer would duplicate
  them with less attribution, more risk, and would compete with the mechanisms
  that improve Athanor. **Hyper-customization is configuration + adaptation**; a
  missing capability becomes a built-in tool, not a user extension. The internal
  tool envelope is an internal contract, not a plugin protocol.

## Deferred to 1.x

- **Browser Mode** (restricted).
- **Cloud credential broker** (HITL; local-first tension).
- **Exploration Paths.**
- **Adversarial self-critique + tree search** (M8-T12).
- **Windows / WSL** support.

**Non-goals** (not deferred — deliberately out): multi-user/teams/cloud sync;
cloud-first inference; unbounded autonomy for external/irreversible actions;
unbounded self-modification; every model/hardware combination.

## 1.0.0 acceptance set (draft, bounded)

**GUI (pillars 1 + 8)**
- A full day of real work end to end **without the CLI**: onboarding,
  project interview/plan, presentation, review, digest/approval ledger,
  portfolio, task/DAG, statistics/memory browser, settings, notifications.

**Validated self-improvement (pillar 2)**
- The 0.0.x study's claims reproduce on the frozen benchmark.
- The operator can **approve a learned change, roll it back**, and both are
  recorded with provenance.
- A novel project triggers the novelty reset and does not inherit stale
  specialisation.

**Benchmark (pillar 3)**
- A frozen benchmark v2 is cut at 1.0.0; the regression dashboard compares
  versions; MCE mechanism metrics are reported per stratum.
- Raw outputs can be re-scored by the new benchmark version.

**Trust (pillar 4)**
- §31.3 audit signed; containment gates green; crash/power-loss/upgrade loses no
  state; long-run endurance meets its SLOs.

**Distribution (pillar 5)**
- Signed installers; auto-update; multi-arch Core Pod; fresh-install demo <15
  min on Linux and macOS; rollback works.

**Portfolio (pillar 6)**
- A project's budget/priority is set, enforced, and visible; a morning meeting
  spans projects; machine-time and review-time allocation are explainable.

**Media verifier (pillar 7)**
- A media task is accepted/rejected by deterministic structural checks, not the
  judge; the semantic layer stays advisory and is documented.
