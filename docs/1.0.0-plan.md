## 1. Objective

1.0.0 is where Athanor becomes a **daily driver**: trustworthy, measured,
self-improving, pleasant, and portable. It is not a feature-completeness
milestone.

## 2. Definition of done (bounded)

The five musts plus three committed additions:
- first-class GUI; validated self-improvement; mature benchmark; trust;
  distribution;
- portfolio/multi-project; deterministic media verifier; Statistics/Memory views.

Concretely: a full day of real work **without the CLI**; the 0.0.x study
concluded and a learned change **approved and rolled back**; benchmark v2 frozen
at 1.0.0 with no cross-major regression; §31.3 audit signed; fresh install <15
min on Linux and macOS; rollback works.

## 3. Decisions

| # | Decision |
|---|---|
| D1 | 1.0.0 = the five musts + portfolio + media verifier + Statistics/Memory. |
| D2 | **No** skills runtime, plugin API, or MCP ecosystem ([ADR-0079](adr/0079-no-skills-runtime.md)); built-in tools + adaptability. |
| D3 | The **benchmark** is the controlled study; **v2 frozen at 1.0.0** ([ADR-0075](adr/0075-frozen-corpus-compass.md)). |
| D4 | The **Core Pod** is the only supported runtime ([ADR-0078](adr/0078-core-pod-only-runtime.md)). |
| D5 | Freeze rule: tag only when the acceptance set is green; nothing added after the tag without a 1.x bump. |

## 4. Workstreams

### WS-G — First-class GUI (main focus)

| ID | Deliverable | Acceptance |
|---|---|---|
| G1 | Day loop surfaces: onboarding/qualification, project interview + plan, presentation, review queue, digest/approval ledger, portfolio, task/DAG, settings, notifications | A scripted full day completes without the CLI |
| G2 | Statistics / Memory-Browser: outcomes, cost, insights, chunks, retrieval, compaction, benchmark/evidence | The MCE is observable per project/run |
| G3 | Accessibility, keyboard, responsive; onboarding tutorial state | The day loop is usable without a mouse |

### WS-V — Validation and self-improvement

| ID | Deliverable | Acceptance |
|---|---|---|
| V1 | Execute the 0.0.x study on the frozen benchmark (statistical power, judge calibration, human anchor) | Claims reproduce; confidence intervals reported |
| V2 | Learned selection (technique/model/routing/escalation) with MinSamples, novelty reset, exploration floor | Selection beats the baseline on the benchmark without regression |
| V3 | Approve/rollback a learned change (HITL, provenance, digest ledger) | A change is approved, applied, rolled back, and recorded |
| V4 | Decide weight-level learning (likely 1.x; gate on corpus + frozen judge) | Written decision with evidence or an explicit deferral |

## 5. Acceptance set (bounded)

Mirror of [1.0.0-direction.md](1.0.0-direction.md) §"1.0.0 acceptance set":
one block per must and committed addition. No single aggregate; each block has
its own demonstrable check.

## 6. Order and dependencies

- Start **V1** as soon as 0.0.0 freezes; **B1** freezes at 1.0.0.
- **G1/G2** run in parallel from the start; **P** follows the review queue.
- **M2** (tooling) early: it is a dependency/packaging decision.
- **T** continuously; **D** last (signing keys, auto-update).
- **V4** is a decision after V1, not assumed.

## 7. Out of scope / not planned

Skills runtime, plugin API, MCP ecosystem ([ADR-0079](adr/0079-no-skills-runtime.md));
Browser Mode; cloud credential broker; Exploration Paths; adversarial
self-critique + tree search; Windows/WSL; multi-user/teams/cloud sync;
cloud-first inference; unbounded autonomy or self-modification.

## 8. Risks

| Risk | Mitigation |
|---|---|
| GUI scope creep | The bounded day-loop surfaces + the no-CLI script; everything else is 1.x |
| Media tooling/dependency | Decide M2 early; unsupported is reported, not passed |
| Statistical claims without power | V1 on the frozen benchmark + held-out; report intervals |
| Weight-level learning distracts | V4 is a decision, not a commitment |
| Distribution signing is late | Start key management before D1 |
| Skills/plugin pressure returns | ADR-0079's revisit trigger: a concrete need a built-in tool cannot meet |

## 9. Freeze and tag

Tag **1.0.0** when the acceptance set is green, benchmark v2 is frozen,
`ROADMAP`/`README`/`ARCHITECTURE §32`/`CHANGELOG` are updated, and the version is
stamped. **Then stop.** No scope creep after the tag without a 1.x bump.
